# Ambient audio

`lake-waves-loop.mp3` — a quiet, seamless loop of water lapping at a shoreline.
Not surf, not a soundscape. 30–60 seconds is plenty.

It is started only by the guest's tap on the envelope (mobile browsers require
that), fades in over ~4 seconds to volume 0.16, and can be muted with the
control in the lower-left corner.

If the file is absent, playback fails silently and the mute control hides
itself. Nothing else on the page is affected.

Path and volume live in `assets/js/config.js`.
